# AzureMusicPlayer

簡潔藍色的 Windows 本機音樂播放器，使用 Python / Tkinter / ttkbootstrap。

從 [GitHub Releases](https://github.com/lotes86089/AzureMusicPlayer/releases/latest) 下載 `AzureMusicPlayer.exe` 即可使用。首次執行會在執行檔旁建立 `data/` 儲存播放清單與設定，更新時保留此資料夾。

原始碼儲存庫不包含個人播放清單、歌曲路徑、設定、音樂檔案與 `.venv` 開發環境；Release 只提供程式本體。

## 開啟

請執行 `release/AzureMusicPlayer.exe`，此資料夾為正式輸出位置，已內含 Python、介面與音訊套件，不需另外安裝。搬移時請一併保留 release 內的 data 資料夾，保存播放清單與設定。

支援 MP3、WAV（包含 PCM 24-bit）、FLAC 與 M4A（AAC、ALAC 無損）。MP3 / WAV / FLAC 以 soundfile / libsndfile 串流解碼，M4A 以及以 .mp3 為副檔名的 ASF 封裝音樂，會依實際檔頭以 PyAV / FFmpeg 串流解碼，sounddevice / PortAudio 輸出到 Windows 預設音訊裝置；播放不轉檔；手動更換封面時會更新音樂檔的封面標籤。尚未承諾 APE、DSD 或受 DRM 保護檔案的相容性。M4A 解碼器已包含於執行檔，不需另裝 FFmpeg。實際輸出取樣率支援依音效裝置而定，本版不是獨占或 bit-perfect 輸出。

在歌曲列表按右鍵選「加入歌曲」選擇檔案；右鍵選單也提供「移除」與「打開檔案位置」，後者會在檔案總管開啟該歌曲所在資料夾並選取該檔案；雙擊歌曲或點播放圖示開始播放，空白鍵可切換播放／暫停。支援上一首／下一首、音量、進度拖曳跳轉與清單收合。首次開啟清單為空，之後會自動還原已儲存清單。

歌曲名稱前的 `#` 欄會依目前清單順序編號，加入或移除歌曲後自動重新編號，不變更原始檔名或音樂檔。左側可切換「預設清單」與「我的最愛」，在左側清單列表按右鍵選「新增清單」新增；自訂清單可雙擊重新命名，右鍵可重新命名或刪除；「預設清單」固定保留，不可改名或刪除。每個清單的歌曲獨立，清單名稱、歌曲、順序與目前清單會自動儲存於程式旁的 data/playlists.json，關閉重開仍保留；搬移程式時請連同 data 資料夾一起搬移。

進度列與上一首、播放／暫停、下一首、播放模式圖示整合於上方深藍區，沒有停止按鈕。模式按鈕可循環切換單曲循環（環形箭頭加 1）、順序播放（清單箭頭）、隨機播放（交叉箭頭），預設為順序播放。單曲播畢重播同曲；順序播放於最後一首結束後停止；隨機播放優先選擇其他歌曲。手動切歌會立即播放，切換左側清單不中斷目前播放，播放控制與自動接曲仍使用原播放佇列；雙擊其他歌曲可改播新清單。

可拖曳視窗上、下邊緣調整歌曲清單高度，寬度與上方播放控制區保持固定。收合清單後再展開，會恢復收合前的高度。視窗高度與收合狀態會自動存入 data/settings.json，關閉重開後還原；若螢幕可用高度較小會自動調整，音量設定仍保留。歌曲編號的標題與數字皆置中。

「播放清單」標題右側有放大鏡圖示與搜尋框，左側播放清單和歌曲表格頂端保持對齊，輸入時即時以歌名模糊篩選目前清單，不需按搜尋按鈕；不分英文大小寫，支援全形文字及不連續字元（例如「城光」可找到「城市微光」）。清空搜尋會恢復全部歌曲。篩選不刪除歌曲、不改變儲存內容，也不改變目前播放佇列；顯示的編號保留歌曲在完整清單中的順序。

## 開發與打包

清單會在背景檢查音樂檔案。有問題的歌曲（檔案不存在、無法讀取、沒有音訊內容或實際播放失敗）在編號前顯示紅色驚嘆號，選取時底部顯示原因，歌曲仍保留在清單中。檔案內容或位置狀態變更後會重新檢查，成功播放也會移除錯誤標記。背景檢查只讀取開頭音訊，播放途中才發生的解碼錯誤會在發生時標記。

可從檔案總管將 MP3、WAV、FLAC、M4A 檔案拖入歌曲列表，自動置於目前清單最前方；一次拖入多首時保留批次順序。右鍵「加入歌曲」仍加入清單末端。選取歌曲按 Delete 可移除，支援多選，只移除清單項目、不刪除原始檔案。歌曲可按住左鍵拖曳排序，也可多選後一起移動；藍色橫線顯示插入位置，靠近上下緣會自動捲動，按 Esc 可取消。排序會自動更新編號，不會中斷目前播放。

左側清單與歌曲列表右鍵可匯入／匯出 TTPL（TTPlayer version 4 XML），保留 Unicode 名稱、歌曲順序與路徑。匯入使用檔內清單名稱，同名時自動加序號；檔案不存在或格式尚未支援時仍保留清單項目，播放時提示。舊 M3U 仍可匯入。封面會讀取目前播放歌曲的內嵌圖片；未播放時預覽所選歌曲。封面右鍵可更換並寫回音樂檔，支援 MP3、FLAC、WAV 的封面標籤，亦可重新讀取。正在播放時優先修改目前播放歌曲；寫入期間暫停讀檔，完成後接續播放。

音量會自動儲存至 data/settings.json，關閉重開可還原，包含 0% 靜音。音量拉桿旁會即時顯示 0–100%；100% 對應舊版 50% 的輸出增益。刪除播放清單前需確認，移除歌曲不需確認。歌曲列表與目前播放標題優先使用支援日文的 Yu Gothic UI 字型。

專案使用 `.venv` 虛擬環境，避免影響其他專案。

在專案資料夾執行以下指令準備環境與打包：

```powershell
python -m venv --without-pip .venv
python -m pip --python .\.venv\Scripts\python.exe install -r requirements-build.txt
.\.venv\Scripts\python.exe azure_music_player.py
.\tools\build.ps1
```




清單區標題固定為「播放清單」。上方長歌名會自動捲動；歌曲列表不顯示滑鼠懸停歌名提示。


## 專案目錄與精簡打包

- `release/`：使用者執行檔及實際的 `data/` 清單與設定。
- `tests/`：回歸測試程式；測試音樂、圖片及清單會即時產生，測試後自動移除。
- `tools/run_tests.ps1`：執行全部測試，不需預先準備測試資料。
- `tools/build.ps1`：依 `AzureMusicPlayer.spec` 建立正式執行檔。
- `tools/video-tools/`：由工作區根目錄移入的 imageio-ffmpeg 開發工具，播放器執行時不使用此目錄，也不會打包進執行檔。
- `.venv/`：專案專用開發環境，日常使用播放器只需 `release/`。

精簡版使用自動依賴分析，移除完整套件收集帶入的命令列／開發工具與 AVIF 圖片外掛，只收集 Windows x64 / Tcl 8 拖放元件，並使用最佳化 Python bytecode。MP3、WAV、FLAC、AAC M4A、ALAC M4A 功能保留。單一執行檔由 67,357,854 bytes 降至 58,037,468 bytes（約減少 13.8%）；解碼器的必要相依 DLL 保留。

測試指令：

```powershell
.\tools\run_tests.ps1
```

`build/`、`__pycache__/` 是可重新產生的中間檔，本次已清除。開發與測試過程可能再產生，均列入忽略清單；不要刪除 `release/data/`。

相容舊式 ASF 封裝的 MP3：依檔頭辨識實際容器，避免把 ASF 當成裸 MP3 而提早結束；孤立損壞封包可略過，連續大量解碼失敗仍會回報錯誤。原始歌曲檔案不需改名或轉檔。

從檔案總管「開啟檔案／選擇其他應用程式」選擇 AzureMusicPlayer.exe 時，會把傳入歌曲加入預設清單並立即播放第一首。原本已在預設清單的同一檔案會直接播放，不重複加入。以命令列傳入一首或多首歌曲亦同。

同一 Windows 登入工作階段只保留一個 AzureMusicPlayer 視窗。重複啟動會喚回原視窗；再次開啟音樂檔會以本機命名管線交給原視窗處理，第二個啟動程序隨即結束。更新舊版後請先關閉原有的舊版視窗，再開啟新版。

播放穩定度：背景執行緒預先解碼，啟動時先準備 1 秒音訊，播放中維持約 3 秒緩衝。音訊輸出回呼只取用記憶體中的 PCM，不再直接讀取或解碼檔案；暫時緩衝不足不會誤判歌曲結束。輸出採較高裝置延遲以增加排程容錯。暫停與進度依實際取用的音訊計算，拖曳進度時會清除舊緩衝並重新預載。

## 品牌與圖示

專案資料夾、主程式 `azure_music_player.py`、類別、視窗標題、單一執行個體識別、清單匯出產生器及執行檔中繼資料均使用 AzureMusicPlayer。正式輸出為 `release/AzureMusicPlayer.exe`，原有 `release/data/` 保留。

第 2 款流線播放鍵 Logo 用於執行檔、視窗與工作列，以及未包含歌曲封面時的預設圖。圖片位於 `assets/AzureMusicPlayer.png`；Windows 多尺寸圖示位於 `assets/AzureMusicPlayer.ico`。

播放紀錄：每次成功播放歌曲及切換播放模式後立即儲存。重新啟動時恢復上次歌曲所在清單、歌曲選取、標題與播放模式（單曲／順序／隨機），按播放後從該首開頭播放，不會自動出聲。歌曲以檔案路徑識別，清單插入或排序不會使記錄指向另一首；已移除的歌曲會安全略過。設定與既有音量、視窗大小共存。
